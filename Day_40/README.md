## Important Learning

- A variable created inside a function is normally local to that function.
- A variable created outside functions is a global variable.
- Local variables cannot be directly accessed outside their function.
- Global variables can be read inside functions.
- The `global` keyword is used when a function needs to modify a global variable.
- If local and global variables have the same name, the local variable is used inside the function.
- Creating a variable inside a function does not make it global.
