# Day 42 — Python File Reading Practice

## Topics Covered

- `readline()` — reads one line at a time
- `readlines()` — reads all lines into a list
- Reading files using a `for` loop
- Extracting data using `strip()` and `split()`
- Searching for a student by name
- Writing multiple lines using `writelines()`
- Converting marks into integers
- Filtering students based on marks
- Handling invalid records using `try` and `except`
- Using `with open()` and UTF-8 encoding
